# RCut v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the opencut-classic clone in `D:\OpenCut` into RCut — a local-only, editor-only video editor shipped as a standalone Windows `.exe` via Tauri v2.

**Architecture:** Strip all server-side code (auth, DB, Redis, API routes, analytics, marketing pages, sounds) from the Next.js app in `apps/web`, switch it to a static export (`apps/web/out`), and wrap that export in a minimal Tauri v2 shell in `apps/desktop`. Editor state stays in the WebView's IndexedDB/OPFS exactly as upstream.

**Tech Stack:** Bun 1.3, Next.js 16 (static export), React 19, Turbo, `opencut-wasm` (prebuilt npm), Tauri v2 (Rust 1.97, WebView2), `bun:test`.

**Spec:** `docs/superpowers/specs/2026-10-03-rcut-design.md`

## Global Constraints

- Work on branch `rcut-v1` in `D:\OpenCut`. Git identity is already configured repo-locally.
- Every commit message ends with a blank line then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Tauri `identifier` is `com.rcut.app` and must never change (WebView2 storage is keyed to it).
- `productName`: `RCut`. Binary: `rcut.exe`.
- Keep the npm dependency name `opencut-wasm` as-is (third-party package). Everything else named "opencut"/"OpenCut" becomes "rcut"/"RCut" or is deleted.
- Keep `LICENSE`'s original copyright line (MIT requirement).
- No server, no Docker, no env vars required to dev, build, or run.
- Sounds (Freesound) feature is removed entirely.
- Code style follows the repo: tabs, double quotes, object-parameter functions (`fn({ a, b })`), `bun:test` tests in `__tests__/` folders next to the code.
- Paths below are relative to `D:\OpenCut` unless absolute. Shell is Git Bash.

```ts
function listSourceFiles({ dir }: { dir: string }): string[] {
```

```ts
export async function downloadBuffer({
	buffer,
	filename,
	mimeType,
}: {
	buffer: ArrayBuffer;
	filename: string;
	mimeType: string;
}): Promise<void> {
	if ("__TAURI_INTERNALS__" in window) {
		const { save } = await import("@tauri-apps/plugin-dialog");
		const { writeFile } = await import("@tauri-apps/plugin-fs");
		const path = await save({ defaultPath: filename });
		if (path) await writeFile(path, new Uint8Array(buffer));
		return;
	}

	const blob = new Blob([buffer], { type: mimeType });
	const url = URL.createObjectURL(blob);
	const downloadLink = document.createElement("a");
	downloadLink.href = url;
	downloadLink.download = filename;
	document.body.appendChild(downloadLink);
	downloadLink.click();
	document.body.removeChild(downloadLink);
	URL.revokeObjectURL(url);
}
```
